# Celtic Cross Tarot

ウェイト版タロットの図柄を使った、ケルト十字スプレッドのブラウザアプリです。

## 使い方

`index.html` をブラウザで開くと使えます。

1. 占いたいことを入力します。
2. 伏せられたカードを10枚選びます。
3. ケルト十字の位置ごとの結果と、最後に総評が表示されます。

## クレジット

カード画像は Rider-Waite-Smith deck の公開スキャンを参照しています。

- Dataset and card scans: https://github.com/metabismuth/tarot-json
- Rider-Waite deck information: https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck
